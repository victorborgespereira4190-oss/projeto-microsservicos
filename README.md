# Projeto de Microsserviços em Java

Projeto acadêmico com três serviços independentes: Produtos, Pedidos e Entregas.

## feito por:
Victor Gabriel Borges Pereira


## Execução
Abra as pastas `produtos-service`, `pedidos-service` e `entregas-service` no IntelliJ IDEA com JDK 17 ou superior. Execute, nesta ordem, `Produtos.java` (porta 8081), `Pedidos.java` (porta 8082) e `Entregas.java` (porta 8083). Use os arquivos `testes.http` para testar as requisições.

Veja também `ARQUITETURA.md`, `LEIA_PRIMEIRO.md` e `MATRIZ_TESTES.md` para documentação e testes.
